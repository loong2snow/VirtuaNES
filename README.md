VirtuaNES is an open-source NES/Famicom emulator originally developed by Norix, released under the GNU General Public License v2.

This project is an enhancement fork of VirtuaNES. It adds preliminary 64-bit support, improves compatibility with various NES mappers, extends peripheral device support, and fixes bugs in the original codebase.
